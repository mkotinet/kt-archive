카카오 아카이브 (KT Archive)

앱스토어 설치 없이 홈 화면에서 진짜 앱처럼 주소창 없는 전체화면으로 빠르게 열람하세요.

1
iPhone Safari 브라우저 하단 중앙의 [공유] 버튼(⎋ 네모 상자 위 화살표)을 누릅니다.
2
나타난 공유 메뉴를 아래로 스크롤하여 [홈 화면에 추가] (+ 모양) 항목을 선택합니다.
3
우측 상단의 [추가]를 누르면 홈 화면에 예쁜 카카오톡 아카이브 아이콘 앱이 생성됩니다!
💡 팁: 홈 화면에 추가된 앱을 실행하면 사파리 주소창이 사라지고 100% 전체화면 네이티브 앱처럼 동작합니다.
1
Chrome 또는 삼성 인터넷 브라우저 우측 상단의 더보기(⋮) 아이콘을 터치합니다.
2
메뉴에서 [홈 화면에 추가] 또는 [앱 설치]를 선택합니다.
3
팝업창에서 [설치] 또는 [추가]를 누르면 스마트폰 앱 서랍 및 홈 화면에 등록 완료!
💡 팁: 브라우저 상단 주소창 옆에 '설치(↓)' 버튼이 떠 있을 경우 해당 버튼을 터치해도 즉시 설치됩니다.
